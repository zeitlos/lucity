## Triggering a deployment

::::tabs

:::tabs-item{label="Dashboard"}
Deploying by hand, picking a branch or commit, and watching build and runtime logs while the release runs.
:::

:::tabs-item{label="CLI"}
`lucity deploy`, its flags, waiting for a rollout to finish, and checking status without leaving the terminal.
:::

:::tabs-item{label="GitHub Actions"}
Auto-deploy on push, and deploying from a workflow with keyless OIDC authentication, so no token is stored.
:::
